# العراق AI — تجربة الإطلاق السينمائية

**تطوير: مصطفى حسين — Mustafa Hussein**

> «عبالكم نتأخر بمشاريعنا؟ هذا مشروعنا الأول كمل ❤️‍🔥»

موقع تفاعلي ثابت (HTML + CSS + JavaScript) بلا مكتبات وبلا خطوة بناء. يعمل على أي استضافة ثابتة.

## التشغيل محلياً

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## النشر

ارفع محتوى المجلد كما هو (Netlify / Vercel / GitHub Pages / Cloudflare Pages). نقطة الدخول: `index.html`.

## 1) وضع رابط العراق AI (مهم)

افتح **`js/config.js`** وعدّل أول متغيّر:

```js
var IRAQ_AI_URL = "";   // ← ضع الرابط الحقيقي هنا، يبدأ بـ https:// أو http://
```

- فارغ أو غير صالح: يبقى زر «جرّب العراق AI الآن ←» معطّلاً ويظهر تنبيه للمطوّر بدل فتح صفحة فارغة.
- صالح: يصبح الزر رابطاً فعلياً. يُفتح افتراضياً في تبويب جديد مع `rel="noopener noreferrer"`؛ لفتحه في نفس التبويب اجعل `OPEN_IN_NEW_TAB = false`.
- لا بد من كتابة البروتوكول (مثلاً `https://...`)؛ الرابط بدونه يُعدّ غير صالح.

## 2) الموسيقى

ضع ملفك الأصلي أو المرخّص في:

```
assets/audio/iraq-ai-theme.mp3     (أو .ogg)
```

- لا يبدأ الصوت إلا بعد ضغط المستخدم «ابدأ التجربة»، وزر الكتم متاح دائماً.
- إن لم يوجد الملف يعمل **صوت احتياطي مولَّد داخل المتصفح** (قلب، طبول، سنطور مُحاكى، Drop) ويظهر تنبيه مع زر «إعادة المحاولة». هذا بديل مؤقت للاختبار وليس موسيقى مُنتَجة بأداة توليد موسيقى.
- برومبت توليد الموسيقى الذي أرسلته جاهز لاستخدامه مع أداة توليد موسيقى مناسبة؛ لم يتوفر لي أداة توليد صوت فعلية، لذلك لم أُنشئ ملف موسيقى نهائياً.
- إن اختلف توقيت مقطوعتك (لحظة الصمت والـ Drop) عدّل القيم في `js/config.js ← t`.

## 3) تعديل التوقيتات والنصوص

كلها في `js/config.js`:

| القسم | الوظيفة |
|---|---|
| `t` | توقيتات المشاهد بالميلي ثانية (النبضات، السؤال، الصمت، الانفجار، الشعار...) |
| `keys` | منحنيات شدة الجمر والتباطؤ وشفافية القلب وانتقال التخطيط |
| `texts` | كل النصوص الظاهرة (العربية) |
| `AUDIO` | مسارات الملف وحجم الصوت |

## بنية الملفات

```
index.html            الهيكل والخلفية (SVG بابلي: بوابة عشتار، زقورة، نقوش مسمارية، دوائر رقمية)
css/style.css         الهوية البصرية، RTL، التجاوب، تقليل الحركة
js/config.js          الإعدادات المركزية (الرابط، التوقيتات، النصوص)
js/audio.js           الصوت: ملف MP3/OGG أو بديل مولَّد، كتم، إيقاف مؤقت
js/heart.js           القلب الناري والجسيمات والموجات والرقم 1 (Canvas)
js/main.js            مخرج التسلسل، الإدخال (ماوس/لمس)، الرابط، الجودة
assets/audio/         ضع الموسيقى هنا
```

## الأداء وإمكانية الوصول

- ثلاثة مستويات جودة (عالية/متوسطة/منخفضة) تُختار حسب الجهاز وتنخفض تلقائياً عند بطء الإطارات. للتجربة اليدوية: `?quality=low` أو `medium` أو `high`.
- احترام `prefers-reduced-motion` (جسيمات أقل، بلا اهتزاز أو بارالاكس).
- لا وميض سريع متكرر: وميض واحد ناعم بطيء عند الكشف.
- تنقل بلوحة المفاتيح للأزرار، وتباين ألوان مناسب، وأهداف لمس ≥ 46px.
- زر «تخطي» للانتقال مباشرة إلى القسم الختامي.
